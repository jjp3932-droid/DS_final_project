# station.c

지하철 역과 노선 데이터를 만들고 찾아오는 파일입니다.

### 내부용 함수 (`static`)
```c
static void* safe_malloc(size_t size);
```
* **입력 / 출력:** 필요한 메모리 크기를 넣으면, 할당된 메모리 주소를 줍니다.
* **내부 로직:** `malloc`으로 메모리를 빌려오고, 실패하면 에러 메시지를 띄운 뒤 프로그램을 바로 종료합니다.

```c
static int segment_length(const RawSegment* raw);
```
* **입력 / 출력:** 구간 데이터 하나를 넣으면, 그 안에 들어있는 역의 개수를 줍니다.
* **내부 로직:** 역 이름 배열을 처음부터 훑으면서 `NULL`이 나올 때까지 개수를 셉니다.

```c
static int get_station_id(const char* name);
```
* **입력 / 출력:** 역 이름을 넣으면, 그 역의 번호(ID)를 줍니다.
* **내부 로직:** 이미 등록된 역이면 기존 번호를 주고, 처음 보는 역이면 전체 역 목록(`stations`) 맨 뒤에 새로 추가한 뒤 새 번호를 줍니다.

```c
static void add_line_to_station(int id, int line);
```
* **입력 / 출력:** 역 번호와 호선 번호를 넣으면, 해당 역에 호선 정보를 기록합니다. (반환값 없음)
* **내부 로직:** 그 역의 호선 목록을 확인해서 이미 들어있는 호선이면 넘어가고, 없으면 새로 추가합니다.

```c
static void add_edge(int a, int b, int line);
```
* **입력 / 출력:** 출발역 번호(`a`), 도착역 번호(`b`), 호선 번호를 넣으면 두 역을 연결합니다. (반환값 없음)
* **내부 로직:** 새 연결 정보(`Edge`)를 하나 만들어서 `a`역의 연결 리스트 맨 앞에 끼워 넣습니다.

### 초기화 및 해제
```c
void init_subway(void);
```
* **입력 / 출력:** 없음 (프로그램 시작할 때 한 번 호출)
* **내부 로직:** 원본 데이터(`RAW_DATA`)를 처음부터 끝까지 읽으면서 역 목록과 구간 목록 배열을 만들고, 바로 옆에 붙어 있는 역끼리 양방향으로 연결합니다.

```c
void free_subway(void);
```
* **입력 / 출력:** 없음 (프로그램 끝날 때 한 번 호출)
* **내부 로직:** 빌렸던 메모리를 반납합니다. 가장 안쪽에 있는 연결 리스트부터 먼저 지우고, 마지막에 큰 배열(`stations`, `lines`)을 지웁니다.

### 역 조회
```c
int find_station(const char* name);
```
* **입력 / 출력:** 역 이름을 넣으면 역 번호(ID)를 주고, 없는 역이면 `-1`을 줍니다.
* **내부 로직:** 전체 역 배열을 0번부터 차례대로 돌면서 `strcmp`로 이름이 똑같은 역을 찾습니다.

```c
const Station* get_station(int id);
```
* **입력 / 출력:** 역 번호(ID)를 넣으면 그 역의 상세 정보(`Station` 주소)를 주고, 잘못된 번호면 `NULL`을 줍니다.
* **내부 로직:** 번호가 정상 범위인지 확인한 뒤, `stations[id]`의 주소를 바로 꺼내줍니다.

```c
int get_neighbors(int id, int* out, int* out_line, int max);
```
* **입력 / 출력:** 역 번호, 결과를 담을 빈 배열 2개(`out`, `out_line`), 최대 개수를 넣으면 인접한 역 개수를 줍니다.
* **내부 로직:** 해당 역에 연결된 간선 리스트를 따라가면서 옆 역 번호는 `out`에, 몇 호선인지는 `out_line`에 차례대로 채워 넣습니다.

---

### 구간 조회
```c
int get_segments_by_line(int line, int* out, int max);
```
* **입력 / 출력:** 호선 번호, 결과를 담을 빈 배열(`out`), 최대 개수를 넣으면 찾아낸 구간 개수를 줍니다.
* **내부 로직:** 전체 구간 목록을 돌면서 해당 호선과 일치하는 구간 번호들을 `out` 배열에 순서대로 담아줍니다.

```c
const Line* get_segment(int seg);
```
* **입력 / 출력:** 구간 번호를 넣으면 그 구간의 상세 정보(`Line` 주소)를 주고, 잘못된 번호면 `NULL`을 줍니다.
* **내부 로직:** 번호가 정상 범위인지 확인한 뒤, `lines[seg]`의 주소를 바로 꺼내줍니다.
